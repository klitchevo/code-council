Code Council

One AI can miss things. A council of AIs catches more.

Get Started View on GitHub

Unanimous

When all models agree, you can be confident it's a real issue. High priority - fix it.

Majority

Most models flagged this. Probably worth investigating - the consensus is strong.

Disagreement

Models conflict on this one. That's useful - you know exactly where to focus your judgment.

Available Tools

Each tool runs your input through multiple AI models in parallel

review_code

General code review for bugs, security, performance, and quality issues.

review_frontend

Accessibility, performance, and UX review for React, Vue, and other frameworks.

review_backend

Security, architecture, and performance analysis for APIs and servers.

review_plan

Review implementation plans before coding. Catch design issues early.

review_git_changes

Review staged changes, diffs, or specific commits directly from your repo.

discuss_with_council

Multi-turn conversations with the AI council. Ask follow-ups with context.

Quick Start

Add to your Claude Desktop config and start reviewing

{
  "mcpServers": {
    "code-council": {
      "command": "npx",
      "args": ["-y", "@klitchevo/code-council"],
      "env": {
        "OPENROUTER_API_KEY": "your-api-key"
      }
    }
  }
}
