Code Council

One AI can miss things. A council of AIs catches more.

Get Started View on GitHub

Unanimous

When all models agree, you can be confident it's a real issue. High priority - fix it.

Majority

Most models flagged this. Probably worth investigating - the consensus is strong.

Disagreement

Models conflict on this one. That's useful - you know exactly where to focus your judgment.

Available Tools

Each tool runs your input through multiple AI models in parallel

review_code

General code review for bugs, security, performance, and quality issues across any language.

Example
Use review_code to check this function: [paste code]
code* language context output_format

review_frontend

Specialized review for UI code focusing on accessibility, performance, and user experience.

Example
Use review_frontend with review_type=accessibility to check this React component
code* framework review_type
React Vue Svelte WCAG

review_backend

Security-focused review for APIs, servers, and backend services. Catches auth issues, injection vulnerabilities, and architectural problems.

Example
Use review_backend with review_type=security to analyze this API endpoint
code* language review_type
Security Performance Architecture

review_plan

Review implementation plans BEFORE coding. Catch design issues, missing edge cases, and risks early when they're cheap to fix.

Example
Use review_plan to analyze this implementation plan: [paste plan]
plan* review_type context
Feasibility Completeness Risks

review_git_changes

Review git changes directly from your repo. Works with staged changes, unstaged changes, branch diffs, or specific commits.

Example
Use review_git_changes with review_type=staged to review my staged changes
review_type commit_hash context
Staged Unstaged Branch diff Commit

discuss_with_council

Multi-turn conversations with the AI council. Each model maintains its own context for authentic diverse perspectives. Ask follow-up questions.

Example
Use discuss_with_council to ask: What's the best way to implement caching here?
message* session_id discussion_type
Multi-turn Context preserved 30min sessions

tps_audit

Toyota Production System analysis for your codebase. Identifies flow inefficiencies, waste, bottlenecks, and quality issues. Generates beautiful HTML reports.

Example
Use tps_audit to analyze this repository with focus_areas=["security", "performance"]
path focus_areas max_files output_format
Flow analysis Waste detection HTML reports

Quick Start

Add to your Claude Desktop config and start reviewing

{
  "mcpServers": {
    "code-council": {
      "command": "npx",
      "args": ["-y", "@klitchevo/code-council"],
      "env": {
        "OPENROUTER_API_KEY": "your-api-key"
      }
    }
  }
}
