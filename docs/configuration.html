Configuration

Config files, environment variables, and MCP client setup

Quick Setup

The fastest way to get started - add to your MCP client config:

{
  "mcpServers": {
    "code-council": {
      "command": "npx",
      "args": ["-y", "@klitchevo/code-council"],
      "env": {
        "OPENROUTER_API_KEY": "your-api-key-here"
      }
    }
  }
}

Other MCP Clients

Any client supporting MCP can use the same config structure.

Config File (Recommended)

For full type support and autocompletion, generate a config file:

# Generate TypeScript config in .code-council/
npx @klitchevo/code-council init

# Generate JavaScript config in project root
npx @klitchevo/code-council init --js --root

# Overwrite existing config
npx @klitchevo/code-council init --force

Config File Locations

Code Council looks for config files in this order:

  1. .code-council/config.ts (recommended)
  2. .code-council/config.js
  3. code-council.config.ts (project root)
  4. code-council.config.js (project root)

Full Config Example

import { defineConfig } from "@klitchevo/code-council/config";

export default defineConfig({
  // Models for each review type
  models: {
    defaultModels: ["model1", "model2"],
    codeReview: ["anthropic/claude-sonnet-4", "openai/gpt-4o"],
    frontendReview: ["anthropic/claude-sonnet-4"],
    backendReview: ["openai/gpt-4o", "google/gemini-2.0-flash-exp"],
    planReview: ["anthropic/claude-sonnet-4"],
    discussion: ["anthropic/claude-sonnet-4", "openai/gpt-4o"],
    tpsAudit: ["anthropic/claude-sonnet-4"],
  },

  // Consensus analysis settings
  consensus: {
    modelWeights: {
      "anthropic/claude-sonnet-4": 1.2,  // Higher weight
      "openai/gpt-4o": 1.0,
    },
    highConfidenceThreshold: 0.8,
    moderateConfidenceThreshold: 0.5,
  },

  // LLM behavior
  llm: {
    temperature: 0.3,      // 0.0-2.0, lower = more focused
    maxTokens: 16384,      // Max response length
  },

  // Session settings for discussions
  session: {
    maxSessions: 100,
    maxMessagesPerModel: 20,
    ttlMs: 1800000,        // 30 minutes
    rateLimitPerMinute: 10,
  },

  // Input limits
  inputLimits: {
    maxCodeLength: 100000,
    maxContextLength: 50000,
    maxModels: 10,
  },
});

Environment Variables

For quick setup without a config file, use environment variables:

VariableDescription
OPENROUTER_API_KEYRequired. Your OpenRouter API key
CODE_REVIEW_MODELSModels for general code reviews (JSON array)
FRONTEND_REVIEW_MODELSModels for frontend reviews
BACKEND_REVIEW_MODELSModels for backend reviews
PLAN_REVIEW_MODELSModels for plan reviews
DISCUSSION_MODELSModels for council discussions
TPS_AUDIT_MODELSModels for TPS audits
TEMPERATUREResponse randomness (0.0-2.0, default: 0.3)
MAX_TOKENSMax response tokens (default: 16384)

Example with Custom Models

{
  "env": {
    "OPENROUTER_API_KEY": "your-api-key",
    "CODE_REVIEW_MODELS": ["anthropic/claude-sonnet-4.5", "openai/gpt-4o"],
    "BACKEND_REVIEW_MODELS": ["anthropic/claude-sonnet-4.5"],
    "TEMPERATURE": "0.5"
  }
}

Configuration Priority

Settings are applied in this order (first wins):

  1. Config file value (if set)
  2. Environment variable (if set)
  3. Default value

Security Best Practices

Never commit your API key to git!

Safe Locations

MCP config files are stored outside your project:

  • Claude Desktop: User config directories (see paths above)
  • Cursor: Global settings
  • Shell environment: ~/.zshrc or ~/.bashrc

Using Shell Environment

# Add to ~/.zshrc or ~/.bashrc
export OPENROUTER_API_KEY="sk-or-v1-..."

Then reference in MCP config:

{
  "env": {
    "OPENROUTER_API_KEY": "${OPENROUTER_API_KEY}"
  }
}

Tip: Config files in .code-council/ should be added to .gitignore if they contain sensitive settings.
