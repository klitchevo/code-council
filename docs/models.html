Model Selection

Choose the right models for your needs and budget

Default Models

Out of the box, Code Council uses these cost-effective models:

Minimax M2.1

Fast, cost-effective reasoning

minimax/minimax-m2.1

GLM 4.7

Strong multilingual capabilities

z-ai/glm-4.7

Kimi K2.5

Advanced reasoning with thinking

moonshotai/kimi-k2.5

DeepSeek V3.2

State-of-the-art open model

deepseek/deepseek-v3.2

These defaults are chosen for:

  • Low cost - Typically $0.01-0.05 per review
  • Good quality - Competitive with premium models
  • Fast response - Lower latency
  • Diverse perspectives - Different architectures catch different issues

Cost Optimization Tips

1. Use Specific Review Types

Instead of "full" reviews, use targeted types to reduce token usage:

Use review_backend with review_type=security

2. Reduce Max Tokens

{
  "env": {
    "MAX_TOKENS": "8000"
  }
}

3. Use Fewer Models for Routine Reviews

For quick checks, 2 models still provide good coverage:

models: {
  codeReview: [
    "anthropic/claude-sonnet-4",
    "deepseek/deepseek-v3.2",
  ],
}

Why Multiple Models Matter

Different models have different blind spots. When they agree, you can be confident. When they disagree, you know where to focus.

  • Claude excels at nuanced security implications and edge cases
  • GPT-4 catches architectural anti-patterns and design issues
  • Gemini spots performance problems and optimization opportunities
  • DeepSeek finds edge cases in complex logic
